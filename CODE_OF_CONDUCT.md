# Code of conduct

`me_fasttext` is a research-prototype repository. The goal of the community
space is to make benchmark evidence, limitations, build notes, and reuse paths
clearer for everyone.

## Expected behavior

- Be precise, respectful, and evidence-oriented.
- Welcome negative results when they are reproducible and clearly reported.
- Keep benchmark discussion focused on corpus, hardware, commands, metrics, and
  limitations.
- Assume good faith when someone reports a build failure, portability issue, or
  unfavorable result.
- Redact private corpora, credentials, internal hostnames, and proprietary logs.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing private data, credentials, proprietary logs, or identifying
  internal infrastructure details.
- Misrepresenting benchmark results, omitting material caveats, or using the
  project to make claims outside its documented scope.
- Repeated off-topic promotion after maintainers ask for a narrower discussion.

## Reporting problems

If a discussion becomes unsafe or unsuitable for a public research repository,
open an issue with the minimum context needed, or contact the repository owner
through the GitHub profile. Reports about private data exposure should avoid
reposting the sensitive material.

Maintainers may edit, hide, or remove comments and issues that violate this
code, especially when they expose private data or make benchmark claims that
cannot be audited.
